# Cloud Video Player

**Cloud Video Player** is an Android mobile and Android TV application designed to stream movies, series, and video collections stored in designated **Dropbox** cloud storage folders (`Series/Season/Episode.mkv` or `Director/Movie.mp4`).

## ✨ Key Features
* **Dropbox-Focused Integration**: Connects seamlessly with Dropbox using a dedicated Dropbox App ID.
* **Advanced Video Formats**: Supports `.mkv`, `.mp4`, `.webm`, `.avi`, `.mov`, `.m4v`.
* **MKV Audio & Subtitle Language Switching**: Switch audio languages and embedded subtitle tracks on the fly.
* **External Subtitle Support**: Automatically detects and loads external `.srt` and `.vtt` subtitle files from the same cloud folder.
* **Subtitle Font Size Settings**: Customizable subtitle text scaling.
* **Vertical / Horizontal View Toggle**: Opens in vertical (portrait) view with full details, with a YouTube-style rotation button to switch instantly to horizontal (landscape) view.
* **Full-Screen Horizontal Player**: Transparent controls overlay with gradient scrims, 5-second auto-hide timer, and tap-to-toggle visibility.
* **Resume Playback**: Automatically persists playback position locally via Room and prompts users to resume from the last known point.
* **Android TV (10-Foot UI)**: Full D-pad navigation and Jetpack Compose for TV (`androidx.tv`) support.
