# Project Rules & Development Guidelines

**MANDATORY RULE 1 (Documentation Review)**: Before initiating any new development, architectural changes, refactoring, or bug fixes on this project (`CloudVideoPlayer`), you **MUST** thoroughly review project documentation in `docs/`.

**MANDATORY RULE 2 (Documentation Upkeep)**: Update [docs/architecture.md](docs/architecture.md) and [docs/development_notes.md](docs/development_notes.md) whenever architectural changes occur.

**MANDATORY RULE 3 (Git Tracking for New Files)**: Whenever any new class, file, or resource is created in the project, you **MUST** ensure it is staged/tracked in Git (`git add`) so it is never left untracked.
